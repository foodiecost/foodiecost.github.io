# FoodieCost

PWA за изчисляване на себестойност на ястия, десерти и печива — съставки, артикули и разходи се пазят локално в браузъра (IndexedDB), без регистрация и без сървър.

Достъпно на: https://foodiecost.github.io

## Разработка

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Публикуването в GitHub Pages се случва автоматично при push към `main` (виж `.github/workflows/deploy.yml`).
